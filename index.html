IA · A VERIFICAR
Configurar IA local (sem API paga)A verificar Ollama…

O RITMO usa Ollama + Qwen3.5:4b para analisar fotografias no teu próprio computador. Não precisas de chave API, conta ou créditos. A fotografia não sai do computador: o servidor local envia-a apenas para o Ollama em 127.0.0.1.

Passo 1 — Instalar Ollama
Descarrega o Ollama para Windows, instala e abre a aplicação uma vez. É necessário Windows 10 22H2 ou mais recente, driver NVIDIA 551.61+ e Ollama 0.12.7+ para o Qwen3.5.
Descarregar Ollama ↗
Passo 2 — Descarregar o modelo visual
O modelo recomendado é qwen3.5:4b (aprox. 3,3–4,0 GB). O download é feito uma única vez e fica no teu computador.
Instalador alternativo (.bat)
A verificar se o Ollama está instalado e se o modelo já foi descarregado…
Dica: a primeira análise pode demorar mais porque o modelo precisa de carregar para a memória. O modelo de 4B é a opção inicial mais conservadora. Se tiveres uma RTX com 12 GB ou mais de VRAM, podes experimentar 8B; confirma a VRAM com nvidia-smi e testa a memória disponível antes de mudar.
Fotografia selecionada

A fotografia é analisada localmente pelo Ollama neste computador; não é enviada para uma API na cloud. A IA estima quantidades e valores; confirma sempre o resultado. Uma imagem não permite saber com exatidão o peso nem ingredientes escondidos.

PRIVACIDADE & SEGURANÇA

Os teus dados

Os teus registos pertencem-te. Faz backups para os manter seguros e poder transferi-los.

Backup & transferência

RECOMENDADO

Exporta os teus registos para um ficheiro JSON. Podes importar esse ficheiro noutro navegador ou depois de reinstalares o sistema.

Dica: guarda uma cópia do backup num local seguro. O ficheiro contém os teus registos pessoais, por isso não o partilhes com outras pessoas.

Como funciona o armazenamento

LOCAL

Os teus registos continuam guardados no localStorage do navegador. O RITMO mantém uma cópia da gravação anterior e tenta guardar um snapshot automático por dia no próprio localStorage, além de permitir exportar backups. Não é necessária conta. O assistente envia apenas um resumo dos dados selecionados para o Ollama neste computador quando fazes uma pergunta.

Importante
Os registos ficam associados a este navegador e dispositivo. Limpar os dados do navegador, usar outro perfil ou mudar de dispositivo pode fazer com que deixem de estar disponíveis. Exporta backups regularmente.
